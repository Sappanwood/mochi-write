# 自由会话合成交互原型

这是 MWT-024 的隔离设计验证，未接入生产入口、真实数据、模型或存储。当前生产流程仍见 [创作契约](../../CREATIVE_WORKSPACE.md)。内部实施设计位于 ProjectOps ADR root 的 `2026-09-10-free-session-contract.md`（逻辑引用 `project-ops:adr/2026-09-10-free-session-contract.md`）。这里的 OP/收据按钮只模拟状态，不能证明业务授权、CAS 或真实保存。

## 运行与操作

在 Repo 根目录运行：

```bash
node docs/prototypes/free-session/serve.mjs
```

打开输出的 `http://127.0.0.1:<临时端口>`。服务器只返回固定 [index.html](index.html)，不暴露 Repo 目录；Ctrl-C 关闭。也可直接用浏览器打开 HTML。刷新重置合成数据；刷新恢复、断线与真正 OP 恢复由后续生产任务验证。需要自动重演时，保留服务并在另一终端运行（项目已有 Playwright/Chromium）：

```bash
node docs/prototypes/free-session/walkthrough.mjs http://127.0.0.1:<临时端口>
```

1. 初始甲/乙都名叫林岚，分别属于 a/b 组。展开「模拟工具进展」，交错生成甲2/乙2；信息区保持甲1。用组与组内版本选择旧稿。
2. 输入反馈，点「引用到对话」；切到乙组、打开 explorer、返回，核对输入/甲1引用保持。删除引用后输入 `@林岚`，列表显示组/ID/版本；ArrowDown、Enter 或点击选择。
3. 查看甲1并「准备保存此版本」，回讨论发送。目标在发送前未绑定，发送后显示甲1；浏览乙不会换目标。模拟提交响应未知→按原 OP 核实，取消不能把待核实错误标成已撤回。
4. 发送「找到之前那个侦探角色，把职业改成记者并保存」，显示待检索；分别测试模拟后端核验通过、多目标澄清、撤回后迟到核验。演示输入不是通用自然语言授权实现。
5. 「用甲旧稿生成故事」冻结 draft-a-1，随后「从故事发展母版」展示实际母版正文及剥离剧情/关系说明；原 conversation/session 标识不变。
6. 展开实际参考资料，查看 Agent 自主读取的母版 v1 与不可取得的设定 v1；不把当前 v2 冒充旧版，不自动附加引用。
7. 浏览器调整为 390px，在讨论/信息间来回切换，输入、引用、当前旧稿保持。桌面为两个区域，手机仅显示当前区域，explorer 复用信息区。

Chrome DevTools 在 1280×900 浏览器实际输入未发送反馈，点击生成甲2、引用甲1，再切换到 390×844 并切换信息/讨论；观察到旧稿、引用、反馈均保持。保留实际 accessibility 快照 `/tmp/mwt024-mobile-before.txt`、`/tmp/mwt024-mobile-after.txt`。

运行环境首次 sandbox loopback 监听被拒绝，精确授权启动临时原型服务和 Chromium 后完成验证；没有修改长期端口或生产服务。结束后关闭本次服务与浏览器。

## 第一轮 review 修复与复验

独立 review 发现原型在 OP 响应未知时允许发送下一条消息，覆盖旧 target，导致原 OP 无法核实。新增浏览器检查先复现失败：期望保留 `待核实 · OP-demo-1`，实际变成 `未指定`，完整 RED 日志为 `/tmp/mwt024-r1-red.log`。

发送门禁现对 bound/unknown 状态保留原 OP、epoch、未发送输入和引用，提示 `previous_operation_pending`。明确撤回或按原 OP 核实终止后，用户可以再次发送保留的输入；此前收据继续显示。桌面 1280px 与手机 390px 的完整复验均通过，18 组操作中包含“响应未知→输入新消息并引用乙稿→发送被阻止→原 OP 核实甲旧稿→原输入可发送→旧收据保留”，完整 GREEN 日志为 `/tmp/mwt024-r1-green.log`。

同轮修正实施契约中 draftContext 与正式 scope/binding 的分工：已有零章故事首章、已有故事后续章和新故事候选分别冻结可信草稿目标，commit 仍只能消费正式 binding/目标 OP ledger。该文档修正不表示原型实现了业务授权。
