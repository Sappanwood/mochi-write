# Mochi Write 产品规格

## 当前状态与目标

资产库编辑、受控字段筛选、故事阅读、独立快照及导入导出已实现。个人认证已接入 MSAL/JWT，
本地使用签名测试身份验收，真实 Entra/Cosmos 联调留到 MWT-004；Agent 写作仍为后续范围。
面向单一拥有者，把既有本地 Markdown 小说资料迁移为个人 Web 创作工作台。
用户已确认资产可 Web 编辑、故事暂只阅读、后续接入 Agent 写作，MVP 不采用 planner/narrator。

## 首期范围

| 模块 | 目标行为 |
|---|---|
| 访问 | 仅本人 Entra ID 登录，MSAL 接入，后端限定 tenant/oid |
| 资产库 | 浏览、名称/题材/年龄层检索、创建/编辑/删除母版，保留受控标签 |
| 故事阅读 | 作品列表、设定、大纲、人物关系与章节阅读 |
| Agent 写作 | 单 Agent 根据本次要求生成或续写，通过反馈重写 |
| 迁移 | 从既有 Markdown 导入，核对内容与关联，支持 Markdown 导出 |

先交付资产管理与故事阅读，再接入 Agent；内容管理无需等待 Mochi runtime 完成。

## 数据规则

角色母版描述跨故事稳定的内在属性，不包含特定故事剧情和双向人物关系。
创建故事时将选定角色与世界观完整复制为故事所属的初始化快照，来源引用仅用于溯源。
故事内当前设定独立演变并保留版本，不回写母版；母版后续修改或删除不改变故事。
后续加入资产时同样复制快照；双向关系统一归作品设定。
作品包含大纲、设定、角色引用及快照、按序排列的章节。
正文保留 Markdown；UUID、不可变版本、导入导出 v1 与并发规则见 [首期实现契约](CONTRACTS.md)。
导入保留未知 frontmatter 字段及原始名称，明确报告损坏或无法解析的引用，不静默丢弃。

## 写作交互设计基线

在右侧 Agent 侧栏持续对话；会话默认从属于故事，不因切换章节或设定页面重开。
切换故事切换对应会话，资产库使用独立会话，也可主动新建会话。
侧栏展示当前作品、对象和选区，本次要求可结合页面上下文及选定资料提交单 Agent 任务。
发送时固定目标与版本；之后导航不改变正在执行任务的目标。
生成结果先作为草稿阅读；用户可采纳为章节或反馈重写，已有章节修改产生新版本。
采纳检查目标章节的基础版本，冲突时不静默覆盖。页面刷新后可恢复查询任务与结果。
本次上下文引用可查看和调整，不默认发送整部作品。具体控件与版本操作在实现前细化。
接近上下文预算时提示整理或新建会话，不静默调用额外模型整理历史。
页面感知侧栏保持可供其他应用接入的宿主适配边界；首期只实现 Mochi Write 消费者。
这些行为已作为设计方向确认，尚无实现或验收证据。

## 迁移与切换

本地来源为用户现有 novel 资料目录。先导入副本、核对数量、内容和引用，保留原文件。
Web app 作为迁移后的主要写入入口；不做本地双向同步。实际切换与数据导入单独执行并验收。
私人素材和导入产物不进入代码仓库。

## 不在首期范围

故事正文手工编辑器、planner/narrator、多 Agent 编排、多章自动编排、角色扮演、多人协作、
多租户服务、本地双向同步。暂缓能力不建立空接口或通用扩展框架。

## 当前页面行为

资产编辑保存必须携带读入版本；冲突显示错误并保留草稿，可展示服务器最新正文供对照。
草稿只在当前浏览器页面会话内保存，切换资产后可从侧栏返回；刷新/关闭提示未保存内容。
资产删除不删除故事中的既有快照。故事资产页可以从母版复制新的独立快照；失败重试沿用请求标识。
故事设置、大纲、快照与章节以 Markdown 阅读；章节按 order、ID 排序，支持前后章与 URL 刷新恢复。
原始 HTML、外部图片与不安全协议链接不渲染。

目录导入先预检字段、引用、身份与顺序，再确认写入；错误明确显示，不截断内容或静默合并冲突。
导出是包含 Markdown 和校验清单的 ZIP；命令行提供等价目录格式。真实素材迁移和主要写入入口切换尚未执行。
