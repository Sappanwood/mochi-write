# Mochi Write 产品规格

## 当前状态与目标

资产库编辑、受控字段筛选、故事阅读、独立快照及导入导出已实现。个人认证已接入 MSAL/JWT，
本地使用签名测试身份验收；MWT-004 已完成真实 Entra/Cosmos 联调，MWT-014 已发布并验证带故事工具的云端创作会话。
面向单一拥有者，让 AI 在用户维护的人物与世界中写小说给用户阅读。
首页以自由创作会话为主要入口，资产模式提供故事阅读与资产 Web 编辑；正文可独立阅读，暂不提供正文手工编辑器。
旧无工具侧栏的草稿采纳继续兼容，MVP 不采用 planner/narrator。

## 首期范围

| 模块 | 目标行为 |
|---|---|
| 访问 | 仅本人 Entra ID 登录，MSAL 接入，后端限定 tenant/oid |
| 资产库 | 浏览、名称/题材/年龄层检索、创建/编辑/删除母版，保留受控标签 |
| 故事阅读 | 作品列表、设定、大纲、人物关系与章节阅读 |
| Agent 写作 | 单 Agent 根据本次要求生成或续写，通过反馈重写 |
| 迁移 | 从既有 Markdown 导入，核对内容与关联，支持 Markdown 导出 |

先交付资产管理与故事阅读，再接入 Agent；内容管理无需等待 Mochi runtime 完成。

## 数据规则

角色母版描述跨故事稳定的内在属性，不包含特定故事剧情和双向人物关系。
创建故事时将选定角色与世界观完整复制为故事所属的初始化快照，来源引用仅用于溯源。
故事内当前设定独立演变并保留版本，不回写母版；母版后续修改或删除不改变故事。
后续加入资产时同样复制快照；双向关系统一归作品设定。
作品包含大纲、设定、角色引用及快照、按序排列的章节。
正文保留 Markdown；UUID、不可变版本、导入导出 v1 与并发规则见 [首期实现契约](CONTRACTS.md)。
导入保留未知 frontmatter 字段及原始名称，明确报告损坏或无法解析的引用，不静默丢弃。

## 写作交互设计基线

以下为保留的无工具侧栏交互；旧故事会话使用本文「已有故事的创作工作区」。
在右侧 Agent 侧栏持续对话；会话默认从属于故事，不因切换章节或设定页面重开。
切换故事切换对应会话，资产库使用独立会话，也可主动新建会话。
侧栏展示当前作品、对象和选区，本次要求可结合页面上下文及选定资料提交单 Agent 任务。
发送时固定目标与版本；之后导航不改变正在执行任务的目标。
生成结果先作为草稿阅读；用户可采纳为章节或反馈重写，已有章节修改产生新版本。
采纳检查目标章节的基础版本，冲突时不静默覆盖。页面刷新后可恢复查询任务与结果。
本次上下文引用可勾选并预览原文，选区文本可粘贴与调整，不默认发送整部作品。
目标可选择新章节（名称、顺序）或当前章节的新版本；预览固定内容后才能确认发送。
接近上下文预算时提示整理或新建会话，不静默调用额外模型整理历史。
页面感知侧栏保持可供其他应用接入的宿主适配边界；首期只实现 Mochi Write 消费者。
上述行为已有本地行为测试、浏览器测试与真实 Mochi HTTP 集成证据；无工具侧栏的真实云端生成、采纳和页面断开恢复证据见 README。

## 迁移与切换

本地来源为用户现有 novel 资料目录。先导入副本、核对数量、内容和引用，保留原文件。
Web app 作为迁移后的主要写入入口；不做本地双向同步。实际切换与数据导入单独执行并验收。
私人素材和导入产物不进入代码仓库。

## 不在首期范围

故事正文手工编辑器、planner/narrator、多 Agent 编排、多章自动编排、角色扮演、多人协作、
多租户服务、本地双向同步。暂缓能力不建立空接口或通用扩展框架。

## 当前页面行为

最近会话和资产页的关联自由会话可逐条“从列表移除”，确认后在两处列表持久隐藏，刷新仍保持。
聊天、草稿、已保存的故事、章节和资产保留；原链接仍可打开和继续对话，继续对话不自动恢复列表显示。
移除不停止正在运行的任务。失败显示提示并保留列表行供重试；当前不提供恢复列表入口或永久删除。
此操作适用于自由会话，旧版创作入口保持原行为。

资产编辑保存必须携带读入版本；冲突显示错误并保留草稿，可展示服务器最新正文供对照。
资产编辑草稿只在当前浏览器页面会话内保存，切换资产后可从侧栏返回；刷新/关闭提示未保存内容。
资产删除不删除故事中的既有快照。故事资产页可以从母版复制新的独立快照；失败重试沿用请求标识。
故事设置、大纲、快照与章节以 Markdown 阅读；章节按 order、ID 排序，支持前后章与 URL 刷新恢复。
原始 HTML、外部图片与不安全协议链接不渲染。

目录导入先预检字段、引用、身份与顺序，再确认写入；错误明确显示，不截断内容或静默合并冲突。
导出是包含 Markdown 和校验清单的 ZIP；命令行提供等价目录格式。真实素材迁移和主要写入入口切换尚未执行。


Agent 草稿持久化在故事分区，与资产编辑的浏览器临时草稿不同。成功且完整的结果才可采纳；
失败、取消与中断保留只读片段，不能变成正式章节。反馈重写保留原草稿目标，多个草稿竞争同一目标时只有一个可采纳。
提交结果未知时保留固定输入，恢复查询不提交新任务；显式重试沿用同一请求 ID。切换范围不会取消旧任务。
会话历史取自 Mochi，草稿与采纳结果取自应用。没有缓存 usage 时显示未知，不显示推算费用。

## 已有故事的创作工作区

新增故事创作后端支持自然语言意图解释、自主取材、独立草稿和明确授权后新建一章。
“先给我看看”保留草稿；后续保存请求绑定用户所选版本，不重新生成后保存不同文字。
用户无需先勾选全部资料，Agent 自行检索当前故事。角色和世界观仍可由用户维护，第一切片不新增正文编辑器。

章节保存只认业务收据；即使模型执行失败，已保存章节仍可查看，未核实的操作也不显示保存成功。
新消息和取消先撤回旧授权，刷新只查询原任务。故事卡片进入创作主工作区，
用户可新建或选择故事会话、输入自然语言要求；无需预先勾选资料或反复确认已明确的保存请求。
首次发送前可选择模型和该模型支持的思考强度；发送后两项在当前会话固定，刷新后只读显示。
更换模型或强度需新建会话；已有会话沿用最近使用的模型与原思考设置。
首次进入没有会话时由用户主动新建，已有会话按当前浏览器选择或最近创建的会话恢复。

主区域展示原始用户消息、会话回复和本轮工具进展；工具事件按持久游标及 invocation 去重。
桌面会话采用对话与草稿双栏，分别滚动；左栏底部固定输入区，右栏直接阅读草稿。
每轮回复附带该轮草稿入口，右栏可切换历史版本，并保留各版本的阅读位置；独立阅读链接仍可刷新恢复。
手机在「对话／草稿」两种视图之间切换，共用底部输入区，并保留各自滚动位置。
查看草稿后输入区显示当前版本引用，反馈与保存请求携带精确草稿引用；切换版本不覆盖已输入的反馈。
保存此版本会填入明确保存请求，用户发送后才进入授权解释；初始化草稿同时展开本次保存范围。
已保存草稿可直接打开对应正式章节。新草稿完成提示更新，不自动切屏或替换正在阅读的旧稿；
发送反馈保留当前视图，可以继续阅读。工具进展在执行中展开，完成后收起；来源与用量按需查看。
本轮来源只列真正读过的资料，查看时核对读入版本；资料已变化或删除时明确提示，不能拿新版冒充原始引用。

失败、中断、取消和保存状态分别呈现。只有后端收据显示「章节已保存」与正式章节入口，
模型文字自称已保存不生成成果标识。待核实操作提供原任务核实按钮；停止尚未确认时允许重试停止，
阻止同会话新发送。页面刷新仅查询原任务与草稿，不重发模型请求。
提交响应未知时保留当前页面的原请求，先查询原任务；显式重试也沿用同一请求 ID 和输入。
界面显示实际返回的创作与意图解释用量，缺失值为未知，不推算费用。

「阅读章节」「查看故事资料」保留已有阅读界面，阅读页可返回创作会话；
角色库、世界观和旧无工具写作侧栏继续可用。详细 API 见 [故事创作会话契约](CREATIVE_WORKSPACE.md)。
第一切片已通过隔离浏览器、真实 HTTP/Pi 故障验收及真实 deepseek-v4-flash smoke，两种授权路径均保存精确草稿。
2026-09-08 已发布云端工具配置与工作区，独立合成故事验证自主取材、先看草稿后原样保存、直接生成并保存以及刷新阅读；发布证据见 README。

## 从创意开始的会话基础（MWT-016）

后端已支持首次消息建立可恢复会话及预留目标，而不立即创建正式作品。未建立工作从原 session 返回，
没有独立创意列表或业务对象。普通／空书架均可从「更多 → 旧版新建故事」进入，直接输入想法，不要求标题或资产向导。
「创作会话」列表回到原 session，区分未建立与已建立作品。创作页面不挂载旧写作侧栏，不预先加载全量母版。
用户可以在自然对话中提出角色或世界观条件，Agent 先查合法词表、按维度检索摘要，再读命中版本全文。
同名或没有结果时继续缩小条件或询问用户，不自动挑选。已经读取的母版版本固定在该会话，后续母版修改或删除不替换来源。

产品流程允许先形成设定、角色快照和大纲后建立作品，再在原 session 写第一章；也允许确认首章时一起建立作品。
保存首章默认确认本候选相关资料，且允许更新此前已建立的初始资料。初始化包在会话草稿面板及独立阅读页展示作品、
资料全文、来源版本、各项新增／更新与可选首章；选择保存时在输入区展开保存范围。
草稿通过对话重写，不增加差异视图和正文手工编辑。由个人用户决定何时更换 session，已建立的零章作品仍允许新建会话，
不增加自动摘要、压缩或切换。成果按真实收据区分「作品已建立」「首章已保存」「章节已保存」；模型失败不抹掉成果。
仅建立作品时不显示章节成功；保存后保持当前会话，阅读页可返回继续。首条响应未知保留请求，刷新只读核实，不自动重发。


初始化草稿每次对话重写保留独立版本。用户可选择旧版精确保存，保存范围包括作品信息、关联资料及可选首章。
仅建立作品会形成真实的零章作品，后续写章失败不删除作品或资料。已建立但尚无章时，首章候选可新增或修改其关联初始资料，
提交同时核对基础版本；已有章后不再开放初始化工具。资料上限为 8 项，生成角色无需已有母版，复制母版则保留完整独立 Content 与来源。
零章作品与生成角色快照均支持内容导出／再导入；过程草稿、会话与内部初始化状态不属于导出内容。


## 自由会话后端

空白、角色、故事可通过同一自由会话 API 开始讨论，初始资料不构成永久保存目标。每条消息固定显式引用，保存目标由独立意图解释和后端完整候选证据核验后绑定；不明确时澄清。该后端已接通；候选分组、旧稿精确引用和有界资产补全已接入 API，每轮可生成多份候选；角色母版支持明确授权后新建/更新与所选旧稿精确保存，冲突保留候选，母版变动不改变故事快照；同会话可用未保存角色旧稿或母版精确版本建立零章故事或故事加首章，再继续写章；反向从故事资料产生含保留/改写/排除说明的完整独立角色母版，不覆盖来源或同名母版。每轮只正式保存一个明确操作，后轮失败保留前轮成果。新工作区已通过 `#free/new` 与 `#free/conversation/:id` 接入，主导航使用自由会话，旧 v1 链接保留明确访问路径。接口与恢复边界见 [自由会话服务](FREE_SESSION.md)。


自由会话尚未打开资料时以单栏讨论和输入为中心，资料入口可展开双栏；桌面可收起资料或进入专心阅读，返回时保留输入与阅读位置。手机切换讨论和信息视图，开始对话或查看资料后共用底部输入框，支持边读边反馈。信息区一次显示正式详情或一份候选，
「查找资料」使用同一区域并可返回最近内容。成果通过「草稿／版本」选择独立组及组内版本，新稿到达只提示，不抢当前阅读。
`@名称` 轻量补全资产/本会话候选，同名标明范围、类型、组/版本；支持键盘或点击选择、删除与打开精确标记。
信息区“引用到对话”添加相同标记；被动浏览不附加下一条消息，不替换在途保存目标。
不带 @ 也可自然讨论和自主取材；未知目标先检索核验，多对象下“修改这个”澄清，绑定后才显示确切新建/更新目标。
按需参考资料区区分用户显式引用、初始资料和 Agent 实际读取，搜索命中不充当已读来源；旧来源可取得则打开旧版，
不可取得明确提示，当前版本仅用于关系/删除提示。保存只认真实收据，未知结果可核实原任务，输入与引用一直保留。


主导航统一提供新建创作、最近会话、故事书架、角色库和世界观；导入导出与旧版创作入口位于「更多」。桌面使用侧栏，窄屏使用相同内容的紧凑横向导航。角色详情和故事章节默认阅读，基础属性与正文复用同一阅读呈现。角色直接编辑是临时人工草稿，与持久候选分离；往返导航保留人工输入，正式保存以原版本进行冲突检查，浏览／开会话不会把人工草稿送给 Agent。
角色、世界观和故事的新建入口提供可编辑的初始创作意图；已有资产入口显示固定的 initialRefs。会话列表按 session 展示最近消息摘要、易读时间、中文任务状态、草稿组数和正式关联名称，不按角色／故事类型拆分，不重复多资产关联行。保存次数仅统计真实收据；无收据的 committed 显示保存结果待核实。关联名称读取失败时保留类型、短 ID 与正式内容链接。书架与角色／世界观卡片从已有 Markdown 提取最多 96 字短摘要，缺少正文时提示暂无内容摘要；显示记录自身的更新时间，故事资料更新不代表最新章节时间。标题只显示一次，长标题折行截断并可查看完整标题；筛选与分页保持原契约。保存后可阅读正式内容并返回原 session，未发送消息与当前信息阅读保持。世界观支持阅读和显式引用，新会话后端已支持候选预览、同组改写、旧稿读取和目标绑定；正式母版新建、更新与选定旧稿精确保存已接通，共用 OP 核实与冲突保留规则；世界观入口、候选版本与正式资产往返已接通。旧会话保持原能力，显示世界观写入限制和主动新建入口，保留旧聊天、候选和授权边界。

## 单故事资料候选

具备资料能力的新自由会话可预览已有章节故事的角色快照、设定和大纲资料包（1–8 项），每成员身份、基线、全文与来源明确。仅参考不自动入包，缺项不能显示完整候选；反馈不自动换版本基线。旧会话保持原能力。当前后端候选和正式保存已接通，对应成员界面仍待接入。

自由会话结合上下文自然承接选项回答、代词、省略和追加要求；讨论、构思和草稿反馈不需要重述完整指令或提供逐字意图证据。分类格式错误不直接阻断对话。草稿目标暂时无法定位时继续讨论，必要时只问具体问题；正式保存才要求明确解释本轮用户授权、核对对象和版本。历史中的保存要求或 AI 建议不能自动授权本轮写入，未获得授权时明确尚未保存。

## 已开篇故事资料

新自由会话可为单个已开篇作品预览并整包保存 1–8 项资料：新增角色快照、更新指定快照，以及修订既有设定和大纲。新快照可原创或完整复制角色母版、本会话未保存角色候选。预览显示成员范围、来源与基础版本；同组反馈不改变范围，用户可选旧稿原样保存。任一成员冲突时整包不写，既有章节保持原文。收据可打开每项正式资料，后续轮次读取新资料继续写章。旧会话保留原能力，需要用户主动新建以使用资料修订。


## 界面信息层级

故事阅读页以作品名和「继续创作」为主要操作；该按钮携带故事已保存版本打开新自由会话，已有会话从默认收起的「创作与关联会话」返回。章节目录可展开，前后章和 URL 刷新恢复保持；章节标识使用紧凑行，Markdown 标题与正文直接阅读。无标签或基础属性时不保留空元数据区。

自由会话的「查找资料」「草稿」「版本」沿用既有发现与精确版本选择。短标识保留同名对象消歧，完整引用、目标与操作 ID 在详情中查看；正式保存只按收据显示结果，版本冲突与保存待核实仍直接提示。折叠信息不会修改已固定引用、保存目标或授权。界面控件使用无衬线字体，阅读正文与新建页引导标题共用中文衬线字体栈。米白为背景，正文使用深墨灰、辅助文字使用暖灰，墨绿用于主要操作与选中状态。讨论区直接铺在背景上，输入区保留单层圆角轮廓，模型与思考强度使用紧凑工具栏。


自由会话在当前标签页保存桌面布局、讨论滚动位置以及每份精确资料/草稿的阅读位置，刷新恢复；旧浏览器缓存缺少这些字段时沿用兼容默认值。新稿只显示提示，用户主动打开才切换内容。未引用资料时省去空引用行，模型与思考强度使用紧凑工具栏；普通完成状态弱化，失败、冲突和待核实保持醒目。移动端按可视窗口高度调整工作区，并预留安全区；模型请求与保存授权不受布局、软键盘或视图切换影响。

空会话的单栏讨论视图将引导、创作建议和输入区居中组合；首次消息进入会话后，输入区回到底部。打开资料时沿用双栏或手机信息视图；较矮窗口优先保留输入和发送空间，引导内容可滚动。创作建议只在输入为空时填入文字并聚焦输入框，不覆盖已有想法。

## 故事写作指引

故事阅读页提供默认收起的「写作指引」，以独立文本维护文风、节奏和叙事方向，最多 4000 UTF-16 code units。
保存后跨会话保留，清空后保存即移除；不写入故事简介、设定或人物母版。编辑输入仅在当前页面组件内保留，离开故事或刷新前需要保存。
保存检查读入的故事版本，冲突或失败保留输入；可读取服务器最新指引对照，再显式保存。修改指引产生新的故事版本，
可能使使用旧故事基线的保存操作发生冲突，不能静默覆盖。

自由会话在执行前按已确定的故事目标读取当前指引；没有明确目标或候选上下文时，仅在本轮允许访问的故事唯一时采用该故事指引。
多故事不猜测，不把参考故事的指引带入新故事或角色／世界观候选。每轮指引与执行输入一同固定；修改或清空只影响后续执行，
不改写在途内容或已生成草稿。「本轮写作指引」可查看实际固定的全文和来源故事版本，旧任务没有该记录时不补造。
指引只控制创作表达，不是剧情事实或保存授权；本轮明确要求优先，原样保存旧稿仍保存精确旧稿。
旧故事创作会话与无工具写作侧栏同样注入故事指引；指引随内容导出／导入保留。首版由用户在故事页维护，不新增 Agent 修改指引工具。
